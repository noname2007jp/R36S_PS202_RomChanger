# R36S PS202 ROM Changer

Windows向けのPS202 ROM入れ替え・サムネイル編集ツール、およびROM・画像の一括コピー／gamelist.xml生成ツールです。

## ROM・画像関連付けツール

- Windows用の単体EXEをGitHub Actionsでビルドします（インストール不要）。
- ROM保存元の上位フォルダを指定すると、配下のサブフォルダも含めてROMを検索します。
- ROM一覧から選択したROMを処理対象から外せます。選択フォルダ内のROMもまとめて外せます。元ファイルは削除されません。
- 画像選択画面では画像をプレビューできます。
- 画像が指定されているROMはその画像を使用します。
- 画像が未指定のROMには、システム別のハードウェア風イラストとROMタイトルを組み合わせたPNG画像を自動生成します。画像素材をインターネットから取得する必要はありません。
- 画像はROM名を基準に保存し、各出力フォルダの `images` に配置します。
- 元のフォルダ構成を維持し、フォルダごとに `gamelist.xml` を生成します。
- 既存のROM、画像、gamelist.xmlがあれば上書きせず中止します。
- ZIPなどの対応ROMは展開せずにコピーします。

### EXEの取得方法

1. GitHubの **Actions** タブを開きます。
2. **Build Windows EXE** ワークフローを選択します。
3. 成功した実行を開き、Artifacts の `PS202_ROM_Gamelist_Builder-Windows` をダウンロードします。
4. ZIPを展開し、`PS202_ROM_Gamelist_Builder.exe` を実行します。

## 既存ROM Changer

従来のROM入れ替え・サムネイル編集ツールの説明やファイルは維持します。

## 注意

- 自動生成画像はシステムを示す汎用イラストで、実機写真やゲームの公式パッケージ画像ではありません。
- 実機用のXMLタグ値は提供されたサンプルをもとに設定しています。実機での動作確認は必須です。
- 初回は本番SDカードではなく、バックアップまたはテスト用フォルダで生成結果を確認してください。
- 既存の `gamelist.xml` が存在するフォルダでは上書きせず停止します。既存XMLへの追記／統合は今後の拡張対象です。
