# R36S PS202 ROM Changer

Windows向けのPS202 ROM入れ替え・サムネイル編集ツールです。

## 機能（初期版）
- ROMフォルダーと入れ替え元／入れ替え先ROMを選択
- `gamelist.xml` を**読み取り専用**で参照し、`<path>` と `<image>` から入れ替え先ROMとサムネイルのファイル名を特定
- 入れ替え先ROM、サムネイル画像を連番付きでバックアップ
- 入れ替え元がZIPなら内容を入れ替え先のZIP名で再パッケージ、通常ファイルなら入れ替え先がZIPのときZIPに格納
- ローカル画像を選択し、タイトル文字を埋め込み、既存サムネイルと同じ寸法で保存
- Wikimedia Commonsから画像候補を検索（ネット接続が必要）
- XML自体は変更しない

## 必要環境
- Windows 10/11
- Python 3.10+
- Pillow

## 起動
```powershell
py -m pip install -r requirements.txt
py main.py
```

## 注意
- 最初はROMのバックアップを確認してから実行してください。
- 本体がUSB接続時にWindowsからドライブとして見えない場合、このツールから直接選択できません。Windowsでアクセス可能なドライブ／フォルダーが必要です。
- ネット画像の利用条件は配布元ごとに確認してください。Wikimedia Commonsの候補はライセンス情報と出典URLを表示します。
- 初期版です。実機での動作確認は利用者側で行ってください。
